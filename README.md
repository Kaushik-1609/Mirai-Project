# MSOT LEARN
A mobile-first gamified learning platform prototype matching the supplied HTML/script structure.

## Run
Open `index.html` in a browser, or serve the folder with a local static server.

## Demo
- Login or create a local demo account.
- Complete Daily Quiz to earn XP.
- Toggle anonymous leaderboard mode.
- Edit XP rules in the Admin XP Economy section.
- Data is persisted in localStorage.

## Production next step
Replace localStorage auth/state with Supabase Auth + PostgreSQL/Prisma, and move all XP scoring to server-side transactions. Never trust frontend XP values in production.
